# Due Passi · Команда ресторана

Telegram Mini App для обучения сотрудников ресторана. Приложение работает локально и подготовлено к серверному запуску.

## Запуск

1. Установите Node.js версии 22.13 или новее. Если используете `nvm`, выполните `nvm install 22`, затем `nvm use 22`.
2. В папке проекта выполните `npm install`.
3. Запустите приложение командой `npm run dev`.
4. Откройте `http://localhost:3000`.

Локальный и серверный код сотрудника: `1111`.

Локальный и серверный код администратора: `8475`.

## Подключение к Telegram

1. Откройте в Telegram бота **@BotFather**.
2. Создайте бота командой `/newbot` и сохраните выданный токен.
3. Добавьте токен на сервер как секрет `TELEGRAM_BOT_TOKEN`.
4. В BotFather выполните `/setmenubutton`, выберите созданного бота и укажите публичный HTTPS-адрес приложения.
5. Открывайте приложение только кнопкой меню бота: тогда Telegram передаст подтверждённые имя, username, фотографию и уникальный ID сотрудника.

Не публикуйте токен бота в коде, переписке сотрудников или Git.

## Сервер

Проект настроен для Sites и Cloudflare D1:

- сайт и серверный API публикуются вместе;
- блюда, сотрудники, сессии и результаты тестов хранятся в D1;
- общий код сотрудника и пароль администратора находятся в секретах сервера;
- изменения структуры базы применяются из папки `drizzle`.

Для новой публикации:

1. Выполните `npm install`.
2. Проверьте проект командой `npm run build`.
3. Зафиксируйте изменения в Git и отправьте их в подключённый репозиторий Sites.
4. Соберите архив через `scripts/package-site.sh` из плагина Sites.
5. Сохраните новую версию в Sites и опубликуйте её.

Для этого проекта публикацию удобнее выполнять через Codex: попросите «опубликуй последнюю версию сайта», и сборка, миграции и развёртывание будут выполнены автоматически.

Перед рабочим использованием сверьте составы и аллергены с актуальными технологическими картами ресторана.
